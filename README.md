## What I'm building: Pkomm Group

[**pkomm-group**](https://github.com/kpk111298/pkomm-group) is a fictional company I break on purpose so I can fix real data engineering problems in public. The businesses are simulated. The problems, the code and the numbers are real.

| Business | What it shows | Live dashboard |
|---|---|---|
| Pkomm Motors | Layered pipeline (raw, cleaned, reporting) with data quality gates | [pkomm-group.streamlit.app](https://pkomm-group.streamlit.app) |
| Pkomm Cart | Incremental loading when payments settle days late, with safe reruns | [pkomm-group-cart.streamlit.app](https://pkomm-group-cart.streamlit.app) |

- 32 automated tests (23 dbt + 9 pytest)
- Every fix written up on the blog, with before and after numbers from a real run
- Every fix mapped to its AWS, Azure, Snowflake and Databricks version

Coming next: a dealer system that rebuilds the last 90 days every morning, and a closed day that stays closed.
